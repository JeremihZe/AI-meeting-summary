# Notion 同步

1. 使用当前会话的 Notion 连接。读取连接要求的 Markdown 规范，把已核对的纪要作为正文，标题作为字段。默认只同步纪要正文，确保其中的时间码、行动项和不确定性说明完整。
2. 按用户指定的页面、数据库或默认会议纪要位置归档。提供链接时直接读取目标，提供名称时搜索并核对路径。按工具要求读取数据库的数据源和字段。优先使用原生会议纪要工具。用户明确要普通页面或指定常规数据库条目时，使用创建页面工具及现有字段。需要变更数据库类型时，先征得用户同意。
3. 同步前检查同目录下的 `notion-sync.json`。再次同步同一份纪要且目的地一致时，读取已保存的页面并更新原有纪要内容，保留页面上其他内容。若目的地不同，按用户指定的新目的地处理。
4. 创建或更新成功后，把返回的链接、页面 ID（若有）、标题和归档位置记录在 `notion-sync.json`，并向用户返回链接。写入结果不明确时，先查找已保存的纪要再决定是否重试。遇到连接或权限问题，交付本地文件并说明未同步的原因。
